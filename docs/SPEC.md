# ゲーム仕様

## 画面
- canvas 960 x 540、固定タイムステップ 60fps
- 座標は左上原点、Y軸下向き

## ステージ
- 地面：x=180〜780、y=420 の板
- 浮島：x=250〜380 / y=300、x=580〜710 / y=300
- 画面外（x<-100, x>1060, y>700）に出たらミス（撃墜）

## キャラクター
- 当たり判定は矩形のみ
- サイズ 40 x 60
- 重力 0.8 / 落下速度上限 16
- 地上移動速度 5 / 空中移動速度 4
- ジャンプ初速 -14、空中ジャンプ1回（計2段ジャンプ）
- ストック制、各3機

## ダメージと吹っ飛び
- ダメージは0%から加算（上限999%）
- 吹っ飛び速度 = (基礎吹っ飛び + 蓄積ダメージ × 0.12) × 技の倍率
- 吹っ飛び中は操作不能、速度が3以下で操作可能に戻る
- ヒットしたら両者6フレーム停止（ヒットストップ）

## 技
- 弱攻撃：ダメージ3、基礎吹っ飛び2、倍率0.8、前方 30x40、持続3F、後隙8F
- 横強攻撃：ダメージ10、基礎吹っ飛び5、倍率1.4、前方 50x50、持続5F、後隙20F

## 操作
- 1P：A/D=移動、W=ジャンプ、S=しゃがみ、F=弱攻撃、G=横強
- 2P：←/→=移動、↑=ジャンプ、↓=しゃがみ、Shift=弱攻撃、Ctrl=横強

## グラフィック
- 画像は使わない。canvasの矩形と色で表現（1P=青、2P=赤）
- 既存キャラクター・音源・BGMは一切使わない。すべてオリジナル

## 実装上の補足（仕様に書かれていなかったので決めたこと）
数値はすべて src/config.js にある。

- 吹っ飛び方向：攻撃した側の向きに **45度** 上向き（`KNOCKBACK.ANGLE_DEG`）
- 吹っ飛び速度は毎フレーム **×0.94** で減衰し（`KNOCKBACK.DECAY`）、3以下で操作復帰
- 1回の技で当たるのは1回だけ（持続フレーム中に多段ヒットしない）
- 空中で何も押していないときは横の速度をそのまま保つ（慣性）。地上では即停止
- しゃがみ中は高さ **30**（`FIGHTER.CROUCH_HEIGHT`）、移動不可
- 浮島の上でしゃがみを押すと **すり抜けて落ちる**（6フレーム、`FIGHTER.DROP_THROUGH_FRAMES`）。地面はすり抜けない
- 足場はすべて下からすり抜けられる（上昇中は乗らない）
- 撃墜後の復活位置：1P=左の浮島の上、2P=右の浮島の上（`FIGHTER.SPAWN`）
- 復活直後 **90フレーム無敵**（点滅表示、`FIGHTER.RESPAWN_INVINCIBLE_FRAMES`）
- 攻撃中は当たり判定の四角を黄色で表示する（これが「パンチ」の見た目）
- ストックが0になった瞬間に勝敗表示。**Enter** でもう一度（`KEYS.RESTART`）
- ヒットストップ中に押したキーは捨てずに、止まりが終わってから効く
- 2Pの Shift / Ctrl は左右どちらのキーでもよい
