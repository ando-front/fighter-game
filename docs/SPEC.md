# ゲーム仕様

## 画面
- canvas 960 x 540、固定タイムステップ 60fps
- 座標は左上原点、Y軸下向き

## ステージ
- 地面：x=180〜780、y=420 の板
- 浮島：x=250〜380 / y=300、x=580〜710 / y=300
- 画面外（x<-100, x>1060, y>700）に出たらミス（撃墜）

## キャラクター
- 当たり判定は矩形のみ
- サイズ 40 x 60
- 重力 0.8 / 落下速度上限 16
- 地上移動速度 5 / 空中移動速度 4
- ジャンプ初速 -14、空中ジャンプ1回（計2段ジャンプ）
- ストック制、各3機

## ダメージと吹っ飛び
- ダメージは0%から加算（上限999%）
- 吹っ飛び速度 = (基礎吹っ飛び + 蓄積ダメージ × 0.12) × 技の倍率
- 吹っ飛び中は操作不能、速度が3以下で操作可能に戻る
- ヒットしたら両者6フレーム停止（ヒットストップ）

## 技
- 弱攻撃：ダメージ3、基礎吹っ飛び2、倍率0.8、前方 30x40、持続3F、後隙8F
- 横強攻撃：ダメージ10、基礎吹っ飛び5、倍率1.4、前方 50x50、持続5F、後隙20F

## 操作
- 1P：A/D=移動、W=ジャンプ、S=しゃがみ、F=弱攻撃、G=横強
- 2P：←/→=移動、↑=ジャンプ、↓=しゃがみ、Shift=弱攻撃、Ctrl=横強

## グラフィック
- 画像は使わない。canvasの矩形と色で表現（1P=青、2P=赤）
- 既存キャラクター・音源・BGMは一切使わない。すべてオリジナル

## 実装上の補足（仕様に書かれていなかったので決めたこと）
数値はすべて src/config.js にある。

### 動き（操作感）
- 地上は加速 0.9/F・減速 1.2/F で上限 5。空中は加速 0.35/F で上限 4、何も押さないと ×0.985 でほぼ滑る（慣性）
- 走ってきた勢い（4 より速い）は空中でもそのまま残る
- ジャンプキーを押したまま上昇中は重力が半分（0.5倍）→ ふわっと高く。離すと通常重力（小ジャンプ／大ジャンプ）
- 空中で ↓ を押すと急降下（落下速度 13）
- しゃがみ中は高さ 30、移動不可。浮島の上でしゃがみを押すとすり抜けて落ちる（地面はすり抜けない）
- 足場はすべて下からすり抜けられる（上昇中は乗らない）

### 技
- 技には startup（振りかぶり）がある：弱 2F、横強 5F。その後 持続 → 後隙
- 当たり判定が出る瞬間に斬撃の弧を表示。1回の技で当たるのは1回だけ

### 吹っ飛び（スマブラ式）
- 吹っ飛び速度 = (基礎吹っ飛び + 蓄積ダメージ × 0.12) × 技の倍率（仕様どおり）
- 角度は技ごと：弱 35°、横強 40°（攻撃した側の向きへ）
- 吹っ飛び速度は毎フレーム ×0.95 で減衰。**hitstun = 速度 × 1.5 フレーム**のあいだは操作不能、その後 速度 ≤ 3 で復帰
- 着地時に hitstun が終わっていれば即操作復帰
- くらった側は空中ジャンプが 1 回回復する（復帰ジャンプ）
- ヒットストップ = 3 + 技のダメージ × 0.5（弱 5F、横強 8F、上限 12F）。停止中に押したキーは捨てない
- くらった側は 10F 白く点滅、画面が吹っ飛び速度に応じて揺れる

### 試合の流れ
- 開始時 READY（80F）→ GO!（〜130F）。この間は操作不可（重力だけ働く）
- 撃墜時「KO!」と爆発、復活位置は 1P=左浮島・2P=右浮島、復活後 90F 無敵（点滅）
- ストック 0 で「GAME!」→ 結果画面「○P WINS!」→ Enter でもう一度
- 2P の Shift / Ctrl は左右どちらのキーでもよい

### 見た目
- キャラは頭・胴・腕2本・脚2本（もも＋すね）の人型シルエット。ポーズ: idle / run / jump / fall / crouch / windup / attack / recover / hit
- 背景は夕暮れのグラデーション＋星＋太陽＋山なみ。地面の下に島がぶら下がる
- HUD はスマブラ風：大きなダメージ％（50% 黄 / 100% 橙 / 150% 赤、増えた瞬間ポップ）、ストックは人型アイコン
