# ゲーム仕様

## 画面
- canvas 960 x 540、固定タイムステップ 60fps
- 座標は左上原点、Y軸下向き

## ステージ
- 地面：x=180〜780、y=420 の板
- 浮島：x=250〜380 / y=300、x=580〜710 / y=300
- 画面外（x<-100, x>1060, y>700）に出たらミス（撃墜）

## キャラクター
- 当たり判定は矩形のみ
- サイズ 40 x 60
- 重力 0.8 / 落下速度上限 16
- 地上移動速度 5 / 空中移動速度 4
- ジャンプ初速 -14、空中ジャンプ1回（計2段ジャンプ）
- ストック制、各3機

## ダメージと吹っ飛び
- ダメージは0%から加算（上限999%）
- 吹っ飛び速度 = (基礎吹っ飛び + 蓄積ダメージ × 0.12) × 技の倍率
- 吹っ飛び中は操作不能、速度が3以下で操作可能に戻る
- ヒットしたら両者6フレーム停止（ヒットストップ）

## 技
- 弱攻撃：ダメージ3、基礎吹っ飛び2、倍率0.8、前方 30x40、持続3F、後隙8F
- 横強攻撃：ダメージ10、基礎吹っ飛び5、倍率1.4、前方 50x50、持続5F、後隙20F

## 操作
- 1P：A/D=移動、W=ジャンプ、S=しゃがみ、F=弱攻撃、G=横強
- 2P：←/→=移動、↑=ジャンプ、↓=しゃがみ、Shift=弱攻撃、Ctrl=横強

## グラフィック
- 画像は使わない。canvasの矩形と色で表現（1P=青、2P=赤）
- 既存キャラクター・音源・BGMは一切使わない。すべてオリジナル

## 実装上の補足（仕様に書かれていなかったので決めたこと）
数値はすべて src/config.js にある。

### 動き（操作感）
- 地上は加速 0.9/F・減速 1.2/F で上限 5。空中は加速 0.35/F で上限 4、何も押さないと ×0.985 でほぼ滑る（慣性）
- 走ってきた勢い（4 より速い）は空中でもそのまま残る
- ジャンプキーを押したまま上昇中は重力が半分（0.5倍）→ ふわっと高く。離すと通常重力（小ジャンプ／大ジャンプ）
- 空中で ↓ を押すと急降下（落下速度 13）
- しゃがみ中は高さ 30、移動不可。浮島の上でしゃがみを押すとすり抜けて落ちる（地面はすり抜けない）
- 足場はすべて下からすり抜けられる（上昇中は乗らない）

### 技
- 技には startup（振りかぶり）がある：弱 2F、横強 5F。その後 持続 → 後隙
- 当たり判定が出る瞬間に斬撃の弧を表示。1回の技で当たるのは1回だけ

### 吹っ飛び（スマブラ式）
- 吹っ飛び速度 = (基礎吹っ飛び + 蓄積ダメージ × 0.12) × 技の倍率（仕様どおり）
- 角度は技ごと：弱 35°、横強 40°（攻撃した側の向きへ）
- 吹っ飛び速度は毎フレーム ×0.95 で減衰。**hitstun = 速度 × 1.5 フレーム**のあいだは操作不能、その後 速度 ≤ 3 で復帰
- 着地時に hitstun が終わっていれば即操作復帰
- くらった側は空中ジャンプが 1 回回復する（復帰ジャンプ）
- ヒットストップ = 3 + 技のダメージ × 0.5（弱 5F、横強 8F、上限 12F）。停止中に押したキーは捨てない
- くらった側は 10F 白く点滅、画面が吹っ飛び速度に応じて揺れる

### 試合の流れ
- 開始時 READY（80F）→ GO!（〜130F）。この間は操作不可（重力だけ働く）
- 撃墜時「KO!」と爆発、復活位置は 1P=左浮島・2P=右浮島、復活後 90F 無敵（点滅）
- ストック 0 で「GAME!」→ 結果画面「○P WINS!」→ Enter でもう一度
- 2P の Shift / Ctrl は左右どちらのキーでもよい

### 見た目
- キャラは頭・胴・腕2本・脚2本（もも＋すね）の人型シルエット。ポーズ: idle / run / jump / fall / crouch / windup / attack / recover / hit
- 背景は夕暮れのグラデーション＋星＋太陽＋山なみ。地面の下に島がぶら下がる
- HUD はスマブラ風：大きなダメージ％（50% 黄 / 100% 橙 / 150% 赤、増えた瞬間ポップ）、ストックは人型アイコン

## M3 で足した UX とキャラの作り込み

### キャラクター（render.js）
- 全パーツに濃い輪郭線を先に太く描いてから本体を重ねる（背景に埋もれない）
- 胴は上半分が明るい2トーン。手先・足先に丸を付けて手足の終端を明示
- 顔に明るいハイライト。ときどき**まばたき**（90〜210フレーム間隔で5F）
- **向きの反転がなめらか**（`facingVisual` が `facing` へ補間。くるっと回る）
- 空中では縦速度に応じて**伸び縮み**（上昇で縦長、落下で縦長、着地でつぶれる）
- **1P は黄色いマフラー / 2P は水色の逆立った髪** — ベルレ法の鎖で計算し、走ると後方になびく
  - 節の間隔は毎フレーム厳密に `CLOTH_LEN` に揃える（「離れすぎたら」だけだと縮んで団子になる）
  - 体の真後ろに垂れると見えないので、常に後方へ引く力（`CLOTH_BIAS` / `CREST_BIAS`）を加える
  - 髪は重力をほぼ効かせない（`CREST_GRAVITY`）

### 画面まわり
- **足もとの影**（真下の足場に楕円で落ちる。高いほど小さく薄い）
- **場外の矢印**：画面外に飛んだキャラを画面端の矢印＋「1P 84%」で示す（脈打つ）
- **撃墜時のカメラズーム**：撃墜地点に 1.5 倍まで寄って 24F 止まり、ゆっくり戻る
- **残像**：吹っ飛び速度 9 以上のとき 2F おきに薄いシルエットを残す
- **ダメージ数字のポップアップ**：当たった位置に「10」が浮かび上がって消える
- **コンボ表示**：2 回以上連続で当てると相手の頭上に「3 HIT」

### 操作
- **P / Esc で一時停止**（PAUSE 画面。試合終了後は無効）
- **M で音の ON/OFF**（HUD に現在の状態を表示）

### 音（audio.js）
- WebAudio でその場で合成する。**音声ファイルは一切使わない**（すべてオリジナル）
- サイン波・矩形波・ノイズ＋ローパスだけで、ジャンプ／空中ジャンプ／着地／空振り／
  弱ヒット／強ヒット／撃墜／READY／GO!／GAME!／ポーズ の音を作る
- ブラウザの制約で、最初にキーを押すまで音は鳴らない（そこで AudioContext を作る）

## M4 で足した CPU 対戦とマウス操作

### 入力の作り（controller.js）
「だれが動かすか」を `down('LEFT')` / `pressed('JUMP')` / `aim(self)` という
同じ聞き方に揃えた。Fighter は相手が人か CPU かを気にしない。

- `KeyboardController` … 従来どおりキーボードだけ
- `MouseController` … 移動はキーボード、攻撃はマウス
- `CpuController`（ai.js）… CPU

### マウス＋キーボード操作（1P）
- 移動 A/D、ジャンプ W、しゃがみ S（従来どおり）
- **左クリック＝弱攻撃、右クリック＝横強攻撃**
- **マウスのある方を向いて攻撃を出す**（`MOUSE.DEADZONE` = 12px 以内は向きを変えない）
- 右クリックメニューは canvas 上で抑止。マウス座標は canvas が拡大縮小されていても正しく換算

### CPU（ai.js）
毎フレーム全部考えると人間離れするので `think` フレームごとに判断し直す。
判断の優先順位は上から順に：

1. **場外にいる → 何より先に復帰**（ステージ中央へ入力、落下し始めたら空中ジャンプ）
2. **攻撃が届く**（横 `range` 以内かつ縦 45 以内）→ 弱か横強。相手が 60% 以上たまっていたら横強を選びやすい
3. **近づく**（ただし地面の端 40px 手前で引き返すので自滅しない）
4. 相手が上にいる／ときどきジャンプ

| レベル | 判断間隔 | 攻撃する確率 | 間合い | 復帰の上手さ | 横強を選ぶ確率 |
|---|---|---|---|---|---|
| よわい | 20F | 50% | 60 | 60% | 25% |
| ふつう | 10F | 80% | 54 | 85% | 40% |
| つよい | 5F | 95% | 50 | 100% | 55% |

吹っ飛び中・攻撃中は操作できないので、CPU もその間は入力しない。

### 最初の選択画面
- 「あいて」= 2P（ふたりで）/ CPU よわい / ふつう / つよい
- 「1P の そうさ」= キーボードだけ / マウス＋キーボード
- ↑↓（W/S）で行、←→（A/D）で内容、Enter かクリックで開始
- 試合終了後の Enter はこの画面に戻る（設定を変えて再戦できる）
