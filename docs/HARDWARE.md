# 電子工作連携設計書 — fighter-game × Raspberry Pi

## 概要

スマブラ風対戦ゲームにGPIOボタン・NeoPixel LED・MPU-6050加速度センサーを接続し、リアルな体験を追加する。

## 必要部品

| 部品 | 数量 | 用途 | 参考価格 |
|------|------|------|----------|
| タクトスイッチ（6mm） | 10個 | 1P/2P 操作ボタン | 100〜300円 |
| ブレッドボード（400穴） | 2枚 | 配線 | 300〜500円/枚 |
| ジャンパーワイヤー（オス-メス） | 40本 | GPIO接続 | 300〜500円 |
| WS2812B NeoPixel LEDテープ 1m（60LED/m） | 1本 | ヒットエフェクト | 800〜1500円 |
| MPU-6050 GY-521モジュール | 2個 | 加速度センサーコントローラー | 200〜400円/個 |
| 抵抗 470Ω | 1個 | NeoPixel データライン保護 | 数円 |
| コンデンサ 1000μF | 1個 | NeoPixel 電源ノイズ除去 | 数十円 |

合計目安：2,500〜4,000円

## システムアーキテクチャ

```
ブラウザ（Chromium）
  │  WebSocket（ws://localhost:8765）
  ▼
hardware_server.py（Python）
  ├── GPIO入力 ─── タクトスイッチ（1P/2P）
  │                → xdotoolでキーイベント注入
  ├── GPIO出力 ─── NeoPixel LEDテープ
  │                → ゲームイベントで発光
  └── I2C ──────── MPU-6050 × 2
                   → 傾き/振動 → 移動/攻撃
```

## 実装フェーズ

### Phase 1: WebSocket基盤
- ゲームJSにWebSocketクライアント追加（ws://localhost:8765）
- Pythonサーバー（websockets）をゲームサーバーとは別プロセスで起動
- ゲームイベント（hit, ko, damage）をJSONで送信

### Phase 2: GPIO ボタン
- RPi.GPIO でボタン入力を読み取り（プルアップ）
- xdotool でブラウザにキーイベント注入
- `hardware_server.py` に組み込み

### Phase 3: NeoPixel LED
- rpi-ws281x ライブラリで制御
- hit → 1秒間点滅（被ダメ側の色）
- ko → 虹色フラッシュ3回
- ゲーム進行中は両端が残機数に応じて点灯

### Phase 4: MPU-6050 加速度センサー
- smbus2 で I2C 読み取り（16ms周期）
- X軸傾き → 移動（±15度で入力認識）
- 振り（加速度スパイク検出） → 攻撃
- ボタン併用可能（コントローラーとして使う想定）

## 配線概略図

```
ラズパイ 3.3V ─────────────── MPU1 VCC, MPU2 VCC
ラズパイ GND ──────────────── MPU1 GND, MPU2 GND, NeoPixel GND, ボタン共通GND
ラズパイ GPIO18 ─[470Ω]─── NeoPixel DATA
ラズパイ 5V ─[1000μF]─── NeoPixel VCC
ラズパイ SDA(GPIO2) ────── MPU1 SDA, MPU2 SDA
ラズパイ SCL(GPIO3) ────── MPU1 SCL, MPU2 SCL
MPU1 AD0 ───── GND（アドレス0x68）
MPU2 AD0 ───── 3.3V（アドレス0x69）
各ボタン ─── GPIOピン〜GND（内部プルアップ使用）
```
